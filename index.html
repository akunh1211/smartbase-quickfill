⚡ מילוי מהיר ל-SmartBase

מוסיף כפתור צף ⚡ מילוי מהיר ישירות בתוך smartbase.digital.idf.il שממלא אוטומטית את שלבים 1, 2 ו-3 בלחיצה אחת.

⬇️ התקן תוסף מילוי מהיר (Userscript) 🚗 פתח את SmartBase

📱 התקנה חד-פעמית (דקה אחת)

  1. הורד מה-Play Store את Microsoft Edge או Firefox.
  2. בתפריט הדפדפן היכנס להרחבות (Extensions) והתקן את Tampermonkey (או Violentmonkey ב-Firefox).
  3. פתח את הדף הזה באותו דפדפן ולחץ למעלה על "⬇️ התקן תוסף מילוי מהיר" ← לחץ Install.
  4. פתח את SmartBase — כפתור ⚡ מילוי מהיר יופיע אוטומטית על המסך!
ℹ️ למה לא Chrome רגיל באנדרואיד? כי גוגל חוסמת תוספים בכרום לנייד. ב-Edge ו-Firefox התוספים מובנים ורשמיים, והתוסף גם מתעדכן אוטומטית.
  1. הורד מה-App Store את האפליקציה החינמית Userscripts.
  2. היכנס להגדרות ← Safari ← הרחבות ← Userscripts והפעל הרשאה לאתרים.
  3. לחץ למעלה על "⬇️ התקן תוסף מילוי מהיר" ושמור בתיקיית הסקריפטים של Userscripts.
  4. פתח את SmartBase ב-Safari — כפתור ⚡ מילוי מהיר יופיע אוטומטית!
  1. התקן Tampermonkey ב-Chrome / Edge / Firefox.
  2. לחץ למעלה על "⬇️ התקן תוסף מילוי מהיר" ← Install.
  3. פתח את SmartBase — הכפתור הצף יופיע מיד.
💡 טיפ ליחידה: אחרי שמישהו אחד מזין מסלולים, רכבים ומשלחים — לוחצים בתוסף על ⚙️ רשימות ← העתק קוד שיתוף ושולחים בוואטסאפ לכולם (בלי הת"ז האישית).
