⚡ מילוי מהיר ל-SmartBase

כפתור ⚡ מילוי מהיר ישירות על גבי כרטיס העבודה ב-SmartBase: מסלולים קבועים עם עריכת עצירה, מטרות מועדפות, רכבים, זיכרון קילומטראז' ותעודת זהות קבועה.

⬇️ התקן תוסף אוטומטי (Edge / Firefox / PC) 🧪 פתח דמו אינטראקטיבי לניסיון

📱 בחר את המכשיר והדפדפן שלך:

  1. לחץ על הכפתור הירוק למעלה "העתק התקנה מהירה ל-Google Chrome" (קוד קצרצר שמתעדכן אוטומטית).
  2. בכרום באנדרואיד: לחץ על 3 הנקודות (⋮) ← כוכב ★ כדי לשמור סימניה, ואז לחץ למטה על ערוך (Edit).
  3. שנה את השם ל-sb, מחק את הכתובת בשדה כתובת אתר (URL), והדבק את הקוד שהעתקת ← שמור.
  4. איך מפעילים? כשנמצאים ב-SmartBase, נוגעים בשורת הכתובת, מקלידים sb ולוחצים על השורה עם הכוכב ★ sb (לא לוחצים Enter במקלדת!).
✨ טיפ: אם לאחר לחיצה על ★ sb קופצת הודעה שהאתר חוסם טעינה חיצונית (CSP), עבור ללשונית Edge / Firefox — שם התוסף עוקף כל חסימה ופועל אוטומטית בלי להקליד כלום.
  1. אם רוצים שהכפתור יופיע אוטומטית בלי להקליד sb — פותחים את SmartBase ב-Microsoft Edge או Firefox באנדרואיד.
  2. בתפריט הדפדפן נכנסים להרחבות (Extensions) ומתקינים את Tampermonkey (או Violentmonkey).
  3. פותחים את הדף הזה ולוחצים על הכפתור הכחול "התקן תוסף אוטומטי" ← Install.
💡 טיפ ליחידה: אחרי שמישהו אחד מזין את המסלולים, הרכבים והמשלחים — הוא לוחץ בתוסף על ⚙️ רשימות ← העתק קוד שיתוף ושולח בוואטסאפ לכולם. כל השאר לוחצים ייבא קוד ותוך 2 שניות הכל מוכן!
  1. דרך 1 (אוטומטית): הורד מה-App Store את Userscripts (חינם), הפעל בהגדרות Safari ← הרחבות, והורד את smartbase-quickfill.user.js.
  2. דרך 2 (ללא אפליקציות, גם בכרום/ספארי באייפון): השתמש בדיוק באותה שיטת סימניה חכמה (sb) כמו בכרום אנדרואיד!
  1. הכי מהיר (ללא התקנה): גרור את הכפתור למטה ישירות אל סרגל הסימניות של Chrome!
  2. התקנה אוטומטית (Tampermonkey): התקן Tampermonkey מחנות Chrome ← לחץ על הכפתור הכחול למעלה "התקן תוסף אוטומטי".
  3. כתוסף Chrome עצמאי (ליחידה): בתיקיית הפרויקט יש תיקיית chrome-extension מוכנה לטעינה ב-chrome://extensions (מצב מפתח ← טען פריט לא ארוז) או להעלאה כ-Unlisted לחנות Chrome.
