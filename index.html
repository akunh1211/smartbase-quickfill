SmartBase מילוי מהיר

פותח את SmartBase הרשמי כשכפתור ⚡ מילוי מהיר כבר מובנה בפנים אוטומטית — בלי העתקות, בלי הדבקות ובלי תוספים.

⬇️ הורד והתקן SmartBase ⚡ (אנדרואיד — קליק אחד) 🧪 צפה בדמו האינטראקטיבי

📱 התקנה ב-15 שניות באנדרואיד

  1. לחץ למעלה על הכפתור הסגול "הורד והתקן SmartBase ⚡".
  2. פתח את הקובץ שירד (SmartBase-QuickFill.apk) ולחץ התקן (אם מופיעה שאלה על מקור לא מוכר — אשר פעם אחת).
  3. פתח את האפליקציה החדשה SmartBase ⚡ — כפתור ⚡ מילוי מהיר יופיע אוטומטית על כרטיס העבודה!
🔒 פרטיות מוחלטת: הת"ז, המסלולים והרכבים נשמרים מקומית רק במכשיר שלך. ניתן לשתף את רשימות היחידה בלחיצה מתוך לשונית ⚙️ ניהול רשימות.
🍏 משתמשי אייפון (Safari) או מחשב / Edge ▼
  1. באייפון: התקן מה-App Store את Userscripts (חינם), הפעל בהגדרות ← Safari ← הרחבות, והתקן דרך הכפתור למטה.
  2. במחשב / Edge / Firefox באנדרואיד: התקן את התוסף Tampermonkey ולחץ למטה להתקנה אוטומטית.
